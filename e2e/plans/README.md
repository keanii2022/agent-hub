# Scripted plans

Invented projects for the browser tests of the clipboard. None of them is real.
Each folder is one project; the hub reads only the `PLAN.md` at its top.

| Folder | What it is there to show |
|--------|--------------------------|
| `bakery-orders` | Steps written as tick boxes, part way through, one step being worked on. |
| `kite-shop` | Steps written as numbered headings, part way through, one step being worked on. |
| `lighthouse-log` | A finished plan. |
| `paper-boats` | A plan with no step marked as the one being worked on. |
| `scrambled-notes` | A `PLAN.md` with no steps in it. |
| `tide-tables` | A project with no `PLAN.md`. |

This file sits loose in the folder, so it is not a project and is never read by the hub.
